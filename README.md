# FiveM Garage System

A comprehensive garage system for FiveM servers with multiple garages and vehicle management.

## Features

- Multiple garage locations with customizable spawn points
- Vehicle storage and retrieval with plate number tracking
- Support for vehicle properties and customization

## Requirements

- FiveM server with ESX framework
- MySQL database

## Installation

1. Download the script files
2. Place them in your FiveM server's resources folder
3. Add `start garajeSystem` to your server.cfg file
4. Import the database.sql file into your MySQL database

## Usage

1. Players can access garages by approaching the garage marker
2. Use the menu to store or retrieve vehicles
3. Vehicles are stored with their properties and can be retrieved later

## Configuration

- Edit the `config.lua` file to add or modify garages
- Customize the garage locations and spawn points
- Adjust the database table name if needed
